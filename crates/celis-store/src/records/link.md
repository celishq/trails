# Celis trails

This folder holds the Celis trails of this project: the steps, proofs and patterns that coding agents
recorded while they worked on it. `celis link` writes it, and it is safe to commit.

Each `.json` file is one record, a signed note. Do not edit or delete a record by hand: a changed record
no longer verifies.

Celis turns your corrections into patterns that every agent keeps, in every project. To install it, run
`curl -fsSL https://celis.ai/install.sh | sh`, then add the plugin for your agent:
https://github.com/celishq/trails.
